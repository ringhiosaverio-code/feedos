# FeedOS 16.1

Il sistema operativo del mangimificio in un unico file HTML: formulazione a costo minimo, acquisti, produzione, qualità e tracciabilità, commerciale, economia ed ESG (cruscotto di maturità, questionario guidato, acqua, rifiuti, Scope 1-2-3 e i 49 indicatori della tesi). Funziona senza rete e senza server; i dati restano nel browser.

- **Provala**: apri `index.html` (mangimificio dimostrativo con dati inventati).
- **Guida completa**: [LEGGIMI.md](LEGGIMI.md) · novità: [CHANGELOG_16.1.md](CHANGELOG_16.1.md).
- **Sviluppo** (Node.js 20+): `npm install`, `npm run build` (file in `dist/`), `npm test`.
